# SlideFlow

AI-powered editor for NotebookLM-generated slide PDFs using Google's Gemini.

## Features

- Import NotebookLM-generated slide PDFs (image-based)
- AI-powered slide editing with Google Gemini
- Save and load editing projects
- Export edited slides as PDF
- Drag and drop slide reordering
- Reference images for consistent AI editing across slides
- Runs entirely in your browser - your data is only sent to Gemini API, never to any other server

## Project Setup

### Prerequisites

- Node.js 22.x
- Yarn 4.x
- Google AI API Key (get one at [https://aistudio.google.com/apikey](https://aistudio.google.com/apikey))

### Install

```bash
yarn install
```

### Development

```bash
yarn dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

```bash
yarn build
```

The built files will be in the `dist` directory, ready for deployment to any static hosting service (Vercel, Netlify, GitHub Pages, etc.).

### Preview Production Build

```bash
yarn preview
```

## How It Works

SlideFlow is specifically designed for editing image-based slide PDFs generated by Google's NotebookLM. Each slide is treated as an image that can be edited using Gemini's vision and generation capabilities.

## Technology Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Google Gemini AI (vision & generation)
- PDF.js (for extracting slide images)
- Zustand (State Management)

## Security Note

This application runs entirely in the browser. Your Google AI API key is stored in localStorage and used directly from the client side. For production use with sensitive data, consider implementing a backend API to proxy Gemini API calls and protect your API key.
