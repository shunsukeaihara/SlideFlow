# SlideFlow 操作マニュアル

SlideFlow は、NotebookLM で生成されたスライド PDF を Google Gemini AI を使用して編集するための Web アプリケーションです。

## はじめに

### 動作環境

- モダンブラウザ（Chrome、Firefox、Safari、Edge の最新版）
- インターネット接続（Gemini API との通信に必要）

### 動作モード

SlideFlow には2つの動作モードがあります：

| モード                 | 説明                           | API キーの管理                  |
| ---------------------- | ------------------------------ | ------------------------------- |
| **クライアントモード** | 静的ホスティング版（Vite SPA） | ユーザーが自分の API キーを設定 |
| **サーバーモード**     | サーバー版（Next.js + Docker） | サーバー側で API キーを管理     |

使用中のモードは設定画面で確認できます。サーバーモードでは API キーの設定は不要です。

### 特徴

- **AI による画像編集**: プロンプト（指示文）を入力するだけでスライドを編集できます
- **編集履歴**: すべての編集履歴が保存され、いつでも過去の状態に戻せます
- **OCR 機能**: スライド内のテキストを認識し、コピー可能にします
- **プライバシー**: データは Gemini API にのみ送信され、その他のサーバーには送信されません

## 初期設定

> **注意**: サーバーモードを使用している場合、この設定は不要です。API キー関連の UI は表示されません。

### API キーの取得（クライアントモードのみ）

1. [Google AI Studio](https://aistudio.google.com/) にアクセス
2. Google アカウントでログイン
3. 「Get API key」から API キーを作成
4. 作成された API キーをコピー

### API キーの設定（クライアントモードのみ）

1. SlideFlow を開く
2. ホーム画面右上の **歯車アイコン（⚙）** をクリック
3. 「Google AI API Key」欄に API キーを貼り付け
4. **「保存」** をクリック

> **注意**: API キーはブラウザの localStorage に保存され、アプリ全体で共有されます。

## ファイルから始める

ホーム画面の「ファイルから始める」セクションから、以下の2つの方法で作業を開始できます。

### PDF をアップロード（新規プロジェクト）

1. **「PDFをアップロード」** カードをクリック
2. 編集したい PDF ファイルを選択
3. PDF が読み込まれ、各ページがスライドとしてエディターに表示されます

### プロジェクトを開く（既存プロジェクトの再開）

1. **「プロジェクトを開く」** カードをクリック
2. 保存済みの `.sfpj` ファイルを選択
3. プロジェクトが読み込まれ、エディターが開きます

### 最近のプロジェクト

ホーム画面下部に最近編集したプロジェクトの履歴が表示されます（最大10件）。

- サムネイルをクリックすると、そのプロジェクトを直接開けます
- ホバー時に表示されるゴミ箱アイコンで履歴から削除できます
- FIFO で、10件を超える履歴については自動で削除されます

> **注意**: この機能は [Origin Private File System (OPFS)](https://developer.mozilla.org/ja/docs/Web/API/File_System_API/Origin_private_file_system) を使用してブラウザ内にプロジェクトデータを保存しています。OPFS に対応したブラウザ（Chrome 86+、Firefox 111+、Safari 15.2+、Edge 86+）でのみ利用可能です。非対応ブラウザでは「最近のプロジェクト」セクションは表示されません。
>
> **プライベートブラウジング（シークレットモード）について**: プライベートブラウジングモードでは OPFS が利用できないか、ブラウザを閉じるとデータが消去されるため、この機能は正常に動作しない場合があります。

## スライドの編集

### 基本的な編集フロー

1. **左サイドバー** からスライドを選択
2. **中央パネル** にスライドのプレビューが表示される
3. **プロンプト入力欄** に編集指示を入力
4. **「生成」** ボタンをクリック
5. AI がスライドを編集し、結果が表示される

### プロンプトの書き方のコツ

**具体的に指示する：**

```text
タイトルを「AI の未来」から「AI がもたらす変革」に変更してください
```

**スタイルを指定する：**

```text
背景色を青から緑のグラデーションに変更してください
```

**複数の変更を一度に：**

```text
1. タイトルを大きくする
2. 箇条書きの間隔を広げる
3. 右下にロゴを追加する
```

### 共通プロンプトの設定

プロジェクトごとに、すべての編集リクエストに共通で適用される「共通プロンプト」を設定できます。

1. エディター画面右上の **歯車アイコン（⚙）** をクリック
2. 「プロジェクト設定」カードの「共通プロンプト」欄に入力
3. **「保存」** をクリック

**設定例：**

```text
日本語のスライドとして自然な表現を使用してください。
フォントスタイルは元のスライドと統一してください。
```

> **注意**: 共通プロンプトはプロジェクトごとに保存されます。プロジェクトファイル（.sfpj）に含まれるため、プロジェクトを開くと自動的に復元されます。

### スライド情報パネル

プロンプト入力エリアの **「情報」** ボタンをクリックすると、右側にスライド情報パネルが開きます。

このパネルには2つのタブがあります：

#### 編集履歴タブ

- 各履歴には以下が表示されます：
  - 編集日時
  - 使用したプロンプト
  - Before → After の画像比較
  - 参照画像（使用した場合）
- **「この状態に戻す」** をクリックで、その時点の状態に復元
- 最下部にはオリジナル画像が表示され、**「この状態に戻す」** で初期状態に復元可能

#### 詳細タブ

- **現在の画像情報**: 幅、高さ、形式、ページ番号
- **OCR結果**: OCRを実行済みの場合、認識されたテキストブロックが表示されます

## 参照画像の活用

参照画像を使用すると、スタイルの一貫性を保った編集が可能になります。

### 参照画像の選択方法

1. プロンプト入力欄の上にある **「参照画像」** エリアを開く
2. 以下のタブから参照画像を選択：

| タブ               | 説明                               |
| ------------------ | ---------------------------------- |
| **現在のスライド** | プロジェクト内の他のスライドを参照 |
| **アップロード**   | 外部画像をアップロードして参照     |
| **履歴**           | 過去の編集結果を参照               |

1. 使用したい画像をクリックして選択（複数選択可）
2. プロンプトを入力して生成

### 参照画像の活用例

**スタイルを統一：**

```text
参照画像と同じフォントスタイルで、このスライドのタイトルを編集してください
```

**レイアウトを合わせる：**

```text
参照画像のレイアウトに合わせて、コンテンツを再配置してください
```

**参照画像でスライドの一部を修正する：**

```text
3枚目の参照画像を参考に、スライドの左側の画像を置き換えてください。
```

### 参照画像の順番について

参照画像は選択した順番で「1枚目」「2枚目」...と番号付けされます。プロンプトで「1枚目の参照画像」「2枚目の参照画像」のように指定することで、特定の参照画像を参考にした編集が可能です。

> **ヒント**: 編集対象のスライドは参照画像の後ろに配置されるため、プロンプトでは参照画像の番号のみを意識すれば OK です。

## OCR 機能

スライド内のテキストを認識し、選択・コピー可能にする機能です。

### OCR の実行

1. スライドプレビュー上の **フローティングツールバー** を確認
2. **「OCR」** ボタンをクリック
3. テキスト認識処理が実行される
4. 完了すると、スライド上にテキストの位置が青い枠で表示される

### テキストのコピー

1. OCR 実行後、テキストブロックにマウスを合わせる
2. ツールチップに認識されたテキストが表示される
3. クリックでコンテキストメニューが開く
4. **「コピー」** を選択してテキストをクリップボードにコピー

### OCR ツールバーの操作

| ボタン                   | 機能                                        |
| ------------------------ | ------------------------------------------- |
| **OCR**                  | OCR を実行                                  |
| **👁（目のアイコン）**   | OCR オーバーレイの表示/非表示を切り替え     |
| **🗑（ゴミ箱アイコン）** | OCR キャッシュをクリア                      |
| **−（最小化）**          | ツールバーを最小化                          |

### ツールバーの移動

ツールバーはドラッグして好きな位置に移動できます。ボタン以外の部分をドラッグしてください。

## スライドの管理

### スライドの並べ替え

1. 左サイドバーのスライドサムネイルにマウスを合わせる
2. 左端に表示される **グリップハンドル（⋮⋮）** をドラッグ
3. 目的の位置にドロップ

### スライドの追加

1. 左サイドバーのスライドサムネイルを **右クリック**
2. コンテキストメニューから選択：
   - **「前にスライドを追加」**: 選択したスライドの前に追加
   - **「後にスライドを追加」**: 選択したスライドの後に追加
3. 「新しいスライドを追加」ダイアログが開く
4. 参照画像を選択（オプション）
5. プロンプトを入力
6. **「生成」** をクリック

### スライドの削除

1. 左サイドバーのスライドサムネイルを **右クリック**
2. **「このスライドを削除」** を選択
3. 確認ダイアログで **「削除」** をクリック

> **注意**: プロジェクトには最低 1 枚のスライドが必要です。最後の 1 枚は削除できません。

## プロジェクトの保存と出力

### プロジェクトの保存

1. エディター画面上部の **「保存」** ボタンをクリック
2. `.sfpj` ファイルがダウンロードされる

> **ヒント**: `.sfpj` ファイルには、すべてのスライドと編集履歴が含まれています。後から編集を再開できます。

### PDF へのエクスポート

1. エディター画面上部の **「PDF出力」** ボタンをクリック
2. すべてのスライドが PDF として出力される
3. PDF ファイルがダウンロードされる

### ファイル形式の比較

| 形式    | 用途           | 内容                                 |
| ------- | -------------- | ------------------------------------ |
| `.sfpj` | 編集作業の保存 | スライド、編集履歴、設定をすべて含む |
| `.pdf`  | 完成品の配布   | 現在のスライド画像のみ               |

## トラブルシューティング

### API キーのエラー（クライアントモードのみ）

**症状**: 「APIキーが設定されていません」と表示される

**対処法**:

1. 設定画面で API キーが正しく入力されているか確認
2. API キーに余分なスペースが含まれていないか確認
3. Google AI Studio で API キーが有効か確認

> **注意**: サーバーモードでこのエラーが発生する場合は、サーバー管理者に連絡してください。

### 生成が失敗する

**症状**: 「スライドの生成に失敗しました」と表示される

**対処法**:

1. インターネット接続を確認
2. API キーの利用制限を確認（Google AI Studio のダッシュボードで確認可能）
3. プロンプトが適切か確認（不適切なコンテンツを要求していないか）

### OCR が正しく認識しない

**症状**: テキストが正しく認識されない

**対処法**:

1. OCR キャッシュをクリアして再実行
2. スライドの解像度が低い場合、元の PDF の品質を確認
3. 手書きや特殊なフォントは認識精度が低下する場合があります

### ファイルサイズが大きい

**症状**: プロジェクトファイルのサイズが大きすぎる

**対処法**:

- 編集履歴が蓄積されるとファイルサイズが増加します
- 不要な履歴がある場合は、必要なスライドのみを新規プロジェクトとして保存することを検討してください

## キーボードショートカット

| ショートカット     | 機能               |
| ------------------ | ------------------ |
| `Ctrl/Cmd + S`     | プロジェクトを保存 |
| `Ctrl/Cmd + Enter` | プロンプトを実行   |
| `Escape`           | ダイアログを閉じる |

## 用語集

| 用語               | 説明                                                   |
| ------------------ | ------------------------------------------------------ |
| **プロジェクト**   | スライド、編集履歴、設定を含む作業単位                 |
| **スライド**       | PDF の各ページに対応する編集可能な画像                 |
| **プロンプト**     | AI に対する編集指示（テキスト）                        |
| **参照画像**       | 編集時にスタイルの参考として使用する画像               |
| **OCR**            | Optical Character Recognition（光学文字認識）          |
| **共通プロンプト** | プロジェクト内のすべての編集に共通して適用される指示   |
